# Bericht vom 13.10.2026

 ## Wie startet man Startet man Kali linux auf einer virtuellen Maschine?

 1. Schritt 
 USB Stick mit entsprechender Zipdatei einstecken und herunterkopieren.
 Dann geht man auf VMware workstation Player und drück auf "open a virtuell machine" 
 Hier wählt man die vorher kopierte zipdatei aus falls alles geklappt hat dann sieht man einen login screen.Hier meldet man sich mit Username:kali und ebenfalls mit pasword: kali  an.

 jetzt ist man im Kali linux drinnen und somit ist der 1. Schritt vollbracht 

 ## 2. schritt 
 Oeffnen sie jetzt den Terminal indem sie links oben auf der Leiste auf dem schwarzen Viereck Klicken.
 jetzt werden sie merken das die tastatur auf english ist um diese auf Deutsch umzuändern benötigen sie folgenden befehl
 ```sh
 setxkbmap de 
 ```

 Dann pasted man folgenden befehl im Terminal dieser Installiert Visualstudio code auf dem programm 
```sh
wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"
```
Wenn dies funktioniert hat dan können sie mit folgendem Befehl die version des Vs codes feststellen
```sh
code --version
```

Jetzt können sie einen Ordner erstellen oder  sie haben  bereits einen passendes Verzeichnis dann gehen sie auf diesen  Ordner mit dem Befehl 
```sh
cd Verzeichnissname
```

Falls sonst alles passt dann starten  sie  "Visual studio code" mit 
```sh
code .
```
