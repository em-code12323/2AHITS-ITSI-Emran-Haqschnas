#  Html link öffnen

1. Gehen sie zu den settings und drücken sie dann auf die Seite Pages.
2. machen sie dort einen Rechtsklick auf ihrem Link und öffnen sie diesen in einem neuen Tab.
3. Gehen sie wieder auf Code und öffnen sie ihre Datei
4. Kopieren sie den link und setzen sie es der Url der Datei der anderen zu dann können sie mithilfe dessen ihre Datei in html format anzeigen wenn sie danach ein .html einfügen in die URl
