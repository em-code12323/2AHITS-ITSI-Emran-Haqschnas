# Erstellen von repository

- Öffnen sie Replit.com
- Gehen sie auf eine beliebige datei oder erstellen sie eine Neue
- Drücken sie auf das + rechts oben
- Suchen sie nach git
- Melden sie sich bei github an über der gitpage
- Sie können die Einstellungen beibehalten(default)
- Ledigtlich die Sichtbarkeit sollte auf Öffentlich sein und nicht privat.
- Simultan erstellen sie auf der Github Seite ein Repository.
- Benennen sie es mit folgender Formel <Klasse <fach <name-Nachname
- Gehen sie wieder auf Replit und geben sie den URl der Github Seite an.
- Speichern sie und pushen sie zum Origin
- Syncronisieren sie.
- **Wichtig!!** setzen sie den default branch auf main
- Bennenen sie ihr repository in Github mit der selber formel z.b "2AHITS-ITSI-Emran-Haqschnas" 
-  Ansosten können sie die standart Einstellungen beibehalten.
-  gehen sie wieder auf die replit Seite.
-  Öffnen sie die Git Funktion wählen sie ihre files aus.
-  Drücken auf den blauen stage und commit button.
-  und pushen sie zum origin.
-  Glückwunsch jetzt müssten sie ein repository haben.
