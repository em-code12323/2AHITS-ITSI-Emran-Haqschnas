## In dieser Stunde nutzten wir  hauptsächlich den Befehl vim.Als alternative geht auch der command Nano.
Dieser Befehl öffnet einen Texteditor ,mithilfe diesem kann man Textdateien anlegen und Editieren.
```sh
vim HelloWorld.sh
```
Die .sh bedeutet das es über die Standard shell ausgeführt wird 
Danach geben wir uns Ausführungsrechte mit dem Befehl:

```sh
chmod u+x HelloWorld.sh
```
jetzt könnenn wir es  direkt als Programm mit ausführen 
```sh 

./HelloWorld.sh
```
 Zum testen ob es klappt nutzen wir denn befehl ls -la
 ```sh 
~/workspace$ ls -la
```
