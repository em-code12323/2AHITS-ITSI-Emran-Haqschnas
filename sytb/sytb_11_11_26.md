# Übung 1 (Multiplizierer)
Mit EXPR
```sh
#!/bin/bash
z1=$1
z2=$2

a=$(expr "$z1" \* "$z2")

echo $a
``` 
-----

Mit let 

```sh
#!/bin/bash
z1=$1
z2=$2

let "a= $z1 * $z2"

echo $a
```
Mit \$(( ))
```sh
ergebnis=$((a * b))
echo "Mit \$(( )):
```
